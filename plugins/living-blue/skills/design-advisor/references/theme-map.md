# Living Blue theme map

What's on each page, and who can change what.

## She can change these in Ghost Admin

(Settings → type the name into the search box if a path doesn't match.)

| What | Where |
|---|---|
| Homepage banner headline | Design → Customize → Homepage → *Hero headline* |
| Text under the headline | Settings → Title & description → *Site description* |
| Banner background image | Design → Customize → Brand → *Publication cover* |
| Logo (replaces the site name in the header) | Design → Customize → Brand → *Publication logo* |
| Browser tab icon | Design → Customize → Brand → *Publication icon* |
| Accent colour (buttons, links, date badges) | Design → Customize → Brand → *Accent color* |
| Title font / body font | Design → Customize → *Modern sans-serif* or *Elegant serif* |
| Header layout | Design → Customize → *Navigation layout*: logo left, logo middle, or stacked |
| Featured posts carousel on the homepage | Design → Customize → Homepage → *Show featured posts* (and mark posts as Featured) |
| Top menu / footer menu | Settings → Navigation → Primary / Secondary |
| Footer social icons | Settings → Social accounts |
| About text (shown to visitors on the homepage) | Pages → About |
| Events (add, edit, cancel) | on the site: Events → Manage events (organizers) |
| Any post's feature image, excerpt, title | open the post → post settings |

## Theme code: she can change it with Claude Code (site-editor)

Edited on the test site, then sent to the developer for review.

- Layout of the homepage sections (banner, Upcoming events, Latest newsletters,
  Get involved box), their order, or adding new sections
- How events are listed or how their date badges look
- Newsletter/post card style (outlined cards with a soft shadow)
- The "Get involved" box wording and design
- The grey Previous/Next band at the bottom of posts
- How the banner image is displayed (cropping, the dark overlay, text over it)
- Spacing, font sizes, colours other than the accent colour

## Needs the developer

- How the events calendar, RSVP, printing or sign-up form *work* (their look is
  theme code)
- Emails, new add-ons or packages, anything on the server

## Known open items (already with the developer)

- The current banner image has words in it ("Living Blue in Tennessee"), and
  the banner puts the headline and buttons on top of it, so text may overlap
  and the image may be cropped. The developer's suggested fix is to show that
  image in full above the welcome text. If she raises this, note it's known and
  offer to send a change request saying which option she prefers.
- Footer social links still point to Ghost's placeholder accounts until she
  sets the group's own (self-serve: Social accounts).
